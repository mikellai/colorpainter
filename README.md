# 彩色塗鴉樂園

給兒童與親子使用的線上卡通塗色網站。純 HTML / CSS / JavaScript（ES Modules），不需要安裝套件、不需要後端或登入。

## 啟動方式

網站要透過本機伺服器開啟（瀏覽器會擋住 `file://` 讀取圖庫 JSON 與線稿）。在專案資料夾執行：

```bash
python3 -m http.server 8080
```

然後打開 <http://localhost:8080>。任何靜態伺服器都可以，例如 `npx serve .`。部署時把整個資料夾放到 GitHub Pages、Netlify 等靜態主機即可。

## 功能

| 頁面 | 網址 | 內容 |
| --- | --- | --- |
| 首頁（圖庫） | `#/` | 今日推薦（開始塗色／換一張圖）、搜尋、分類篩選、熱門與最新圖案 |
| 塗色工作區 | `#/paint/<圖案 id>` | 新的塗色作品 |
| 繼續編輯 | `#/work/<作品 id>` | 打開已儲存的作品 |
| 我的作品 | `#/works` | 本機作品列表：繼續畫、下載、刪除 |

塗色工具：油漆桶、畫筆、橡皮擦（只擦顏色，不會擦到線稿）、移動畫布、粗細調整、18 色常用色票、自訂顏色、背景色、撤銷／重做、清除（有確認）、復原到原始線稿、儲存、下載 PNG。

- 縮放與拖動：右下角 ＋／－／符合畫面、兩指捏合、`Ctrl`／`⌘` + 滾輪、觸控板雙指捲動、按住空白鍵拖曳。
- 快捷鍵：`F` 填色、`B` 畫筆、`E` 橡皮擦、`H` 移動、`Ctrl+Z` 撤銷、`Ctrl+Y`／`Ctrl+Shift+Z` 重做、`Ctrl+S` 儲存、`+` `-` `0` 縮放。
- 離開工作區時若有未儲存的變更，會詢問「儲存後離開／不儲存／繼續畫」。
- 右上角「動畫」可以關閉慶祝動畫；系統設定「減少動態效果」時會自動關閉。

### 填色怎麼避免溢出

`js/painter.js` 只用線稿當邊界（不受已塗的顏色影響），每次填色會算兩次：

1. 一般邊界：線稿加粗 1px，處理反鋸齒邊緣。
2. 補缺口邊界：線稿加粗 4px，可補起約 9px 寬的缺口。

如果一般邊界填到的範圍有一大塊是補缺口邊界填不到的，就判斷顏色從缺口漏出去了，改用補缺口的結果。點到線條上不會填色，會提示小朋友往白色區域點。

## 專案結構

```
index.html            頁面骨架
css/style.css         全部樣式（RWD：>860px 側邊工具列；≤860px 工具在下方）
js/app.js             路由（hash）與頁面切換
js/painter.js         塗色引擎：圖層合成、填色、畫筆、撤銷／重做
js/catalog.js         讀取圖庫資料、搜尋
js/storage.js         IndexedDB 作品存取、localStorage 小設定
js/ui.js              引導角色、對話框、提示訊息、慶祝動畫
js/icons.js           線條圖示
js/views/*.js         首頁、塗色工作區、我的作品
drawings/             線稿素材與圖庫資料（與程式分開）
```

## 新增或替換圖案

詳細說明見 [drawings/README.md](drawings/README.md)。簡單來說：

1. 把白底黑線的線稿（SVG 或 PNG）放進 `drawings/<分類>/`。
2. 在 `drawings/drawings.json` 的 `drawings` 陣列加一筆資料。
3. 重新整理網頁。

## 作品儲存在哪裡

- 作品存在瀏覽器的 **IndexedDB**：資料庫 `rainbow-coloring`，資料表 `works`。每筆包含原始線稿（Blob）、上色圖層（PNG Blob）、背景色、縮圖、建立／修改時間。
- 動畫開關、上次用的顏色與筆刷粗細存在 **localStorage**（鍵名以 `rcp:` 開頭）。
- 資料只存在目前這台裝置、這個瀏覽器和這個網址。換裝置、換瀏覽器、用無痕模式，或清除網站資料，作品都會不見，重要作品請先下載。
- 開發時可以在瀏覽器開發者工具 → Application（應用程式）→ IndexedDB 查看或清除。

## 瀏覽器支援

近期版本的 Chrome、Edge、Safari（含 iPad／iPhone）、Firefox。需要支援 ES Modules、Pointer Events、`<dialog>` 與 IndexedDB。
